# Microsoft 365 Service Operations

Use the authenticated Microsoft 365 admin center and confirm tenant, current time zone, affected services, and requested time window. Read [references/service-health.md](references/service-health.md).

This skill is read-oriented by default. Do not dismiss messages, change organizational release preferences, or post communications merely because the user asked for status.

Correlate incident IDs, service names, status, start/update timestamps, affected features, tenant impact, workarounds, and next-update commitments. Distinguish a Microsoft-published incident from a local inference based on user symptoms.

Report current status, last update, known impact, workaround, next expected update, and whether local diagnostics are still required.
