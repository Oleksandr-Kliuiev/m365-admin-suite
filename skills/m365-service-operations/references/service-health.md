# Service health and messages

## Service Health

Filter by active/resolved status and relevant service. Open exact incident/advisory ID and record classification, status, affected service/features, tenant impact, start time, latest update, workaround, history, and next update. Page through filtered history when the requested window exceeds the first page.

## Message Center

Resolve exact post ID and inspect category, services, published/updated dates, rollout dates, tenant relevance, required administrator action, and links. Separate general roadmap announcements from changes that affect this tenant.

## Operational report

State which facts Microsoft published and which conclusions are inferred from correlation with local symptoms. Include timestamps and time zone. Do not claim resolution until the incident status or observed service behavior supports it.
